# Chicago Paulie's — Shopify Theme

Custom Shopify Theme for Chicago Paulie's Restaurant.

## Shopify GitHub Integration
This repository is configured to connect directly with Shopify via **Online Store > Themes > Add theme > Connect from GitHub**.

### Structure:
- `layout/theme.liquid`: Main layout with Liquid tags
- `sections/`: Modular customizable sections (header, hero, highlights, menu, about, reviews, catering, location, footer)
- `snippets/cart-drawer.liquid`: Native Shopify slide-out cart drawer
- `templates/`: Shopify page templates (index, product, collection, cart, 404, page)
- `assets/`: Theme CSS styles and JavaScript logic
- `config/`: Theme settings schema
- `locales/`: Localization files
